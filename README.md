# Поиск нотариуса по адресу

Адресный поиск и карта 61 нотариального участка Волгограда и Волжского.

Адрес страницы: https://tokatim.github.io/notary-map-volgograd-volzhsky/

Встраивание в Django CMS использует тот же адрес с `index.html?embed=1`. Изменять существующий iframe после обновления файлов не требуется.

## Как изменить адрес или телефон нотариуса

1. Откройте `contacts.js` в этом репозитории и нажмите значок карандаша.
2. Найдите нужное ФИО либо номер участка.
3. Измените только `address` и `phones`. Телефоны перечисляются строками в квадратных скобках. Для отсутствующих данных используйте пустую строку и пустой массив.
4. Нажмите **Commit changes** и дождитесь успешной сборки GitHub Pages. При необходимости обновите страницу карты в браузере.

Пример:

```javascript
"address": "Волгоград, проспект Металлургов, 11",
"phones": ["+7 (8442) 72-66-00"]
```

Телефонные ссылки создаются автоматически. Номера ключей участков не меняйте. Поле `name` служит ориентиром при редактировании контактов; замена самого нотариуса требует отдельного обновления состава участков.

## Данные и источники

Границы и распределение адресов подготовлены по предоставленному перечню участков по состоянию на 03.08.2021 и принятым уточнениям.

60 адресов контор и 63 номера телефона выбраны из опубликованного палатой графика на май 2026 года: https://volgogradnotary.ru/files/grafik_raboty_notariusov_08.05-11.05.2026.pdf . Контакты Токарева Д. С. подтверждены владельцем карты. Контакты участка № 25 оставлены пустыми по его просьбе.

Для Тушканова С. А. выбран номер 62-45-45 из документа палаты; в отдельных справочниках встречается 65-45-45. Этот номер желательно дополнительно подтвердить. Сведения о конторах могут изменяться после даты источника.

Основной поиск выполняется в браузере. Яндекс предоставляет подложку и дополнительный геокодер согласно условиям и лимитам аккаунта. `config.js` содержит браузерный API-ключ; ограничение доменов настраивается владельцем в кабинете Яндекса. При недоступности Яндекса сохраняются схема и встроенный поиск.
