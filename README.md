# Поиск нотариуса по адресу

Статическое приложение для поиска нотариального участка по адресу в Волгограде и Волжском: 61 участок, карта и адресный справочник.

Приложение работает без серверной базы данных. Основной поиск выполняется в браузере. Подложка и дополнительный геокодер используют JavaScript API Яндекс Карт.

## Размещение

Разместить содержимое этого каталога в корне публичного репозитория и включить GitHub Pages для основной ветки, каталог `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

После получения адреса Pages владелец ключа Яндекс Карт должен добавить точный домен страницы карты в список разрешённых доменов ключа, сохранив существующие ограничения. `config.js` содержит браузерный API-ключ, который по устройству приложения доступен посетителям. Серверных паролей и токенов в комплекте нет.

В Django CMS страница встраивается через iframe с HTTPS-адресом `index.html?embed=1`. Перед публикацией на сайте палаты проверить загрузку без VPN, адресный поиск, подложку Яндекса и отображение на телефоне.

## Данные

Территориальное распределение подготовлено по предоставленному перечню участков по состоянию на 03.08.2021 и принятым уточнениям. Изменения состава нотариусов и границ после даты источника требуют отдельной проверки.

Геометрия и адресная база используют данные © OpenStreetMap contributors, доступные по Open Database License: https://www.openstreetmap.org/copyright . Атрибуция сохранена в интерфейсе карты.

При недоступности Яндекса остаются схематическая карта и поиск по встроенной адресной базе. API Яндекс Карт используется согласно условиям и лимитам аккаунта владельца ключа.
