# Поиск нотариуса по адресу

Интерактивная карта нотариальных участков Волгограда и Волжского. Поиск по адресу показывает обслуживающего нотариуса, адрес его конторы и телефон.

[Открыть карту](https://tokatim.github.io/notary-map-volgograd-volzhsky/)
